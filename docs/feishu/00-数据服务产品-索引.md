# 数据服务产品

全市场仿真数据与研究能力的**统一数据 Facade**：对内按源适配，中间统一领域能力，对外只留一套 `/v1` + 一套 MCP。

**定稿原则：** 源可变 · 存储可分级 · 对外契约唯一 · MCP 只是投影 · 网关/计费后挂不进领域层
